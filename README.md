# Skill-Based Internship Recommendation System using Python and Machine Learning

## Project Description
The Skill-Based Internship Recommendation System is a web-based application that recommends suitable internship domains based on students' technical skills and academic profiles.

## Technologies Used
- Python
- Machine Learning
- Scikit-Learn
- Pandas
- NumPy
- Streamlit

## Features
- Skill-based internship recommendations
- Academic profile input
- Multiple internship domain recommendations
- Primary and secondary domain suggestions
- Interactive web application

## Internship Domains
- Web Development
- Data Science
- Artificial Intelligence
- Cloud Computing

## How to Run the Project

1. Install the required packages:

   `pip install -r requirements.txt`

2. Run the Streamlit application:

   `streamlit run app.py`
